# Working notes for Claude Code

## Retro after each work loop

After finishing a meaningful loop of work (a roadmap phase, a multi-step feature, a bug-hunting session spanning several CI iterations), write a short retro markdown to `docs/RETRO_<topic>.md` covering:

- **What worked well** — techniques, tools, or sequencing worth repeating.
- **What didn't work well** — wrong assumptions, wasted cycles, things that should be done differently next time.

Keep it concrete and specific to what actually happened in that loop, not generic advice. See `docs/RETRO_PHASE_1-3.md` for an example.
